Kinetiqo Source Code & System Architecture

Kinetiqo is 100% open-source software built under the MIT License. Explore our modular Python 3.14 tech stack and clean SQL repository pattern.

🐍 Backend Core

  • Python 3.14 runtime environment
  • Flask 3.1.3 [async] web framework
  • Click 8.4.1 CLI command interface
  • pandas 3.0.3 telemetry modeling

⚡ Reactivity & UI

  • HTMX 2.0.10 & SSE progress bars
  • DataTables 2.3.7 grid engine
  • Chart.js 4.4.1 canvas graphics
  • Leaflet 1.9.4 interactive maps

🐳 Rendering & Security

  • Playwright & Chromium PNG export
  • flask-compress brotli/gzip engine
  • Flask-WTF & CSRF validation
  • 100% Self-Hosted Assets (Zero CDN)
