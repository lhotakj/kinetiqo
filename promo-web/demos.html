Kinetiqo Video Demos & Feature Walkthroughs

Watch Kinetiqo in action. Recorded screencasts demonstrating activity poster creation, live Strava syncing, and telemetry charts.

1. Activity Poster Generator & High-Res Export

WYSIWYG poster builder walkthrough: aspect ratio toggles (4:3, 16:9, 1:1), custom photo upload, font styling, elevation profile tuning, and pixel-perfect Playwright PNG rendering.

▶

2. Strava Description Auto-Update Engine

Demonstrates setting up 150+ placeholder description templates across 6 activity buckets, live template syntax validation, milestone triggers (🎉), and real-time Strava sync.

3. Power Skills, FTP & Fitness/Freshness Curves

Interactive demonstration of Power Skills radar chart filtering, automated 95% 20-min FTP tracking history, Townsend MAP VO₂max trends, and Banister CTL/ATL/TSB curves.

4. Multi-Provider Leaflet Canvas Maps

Multi-track rendering performance with Canvas layer, switching between 7 tile providers (OSM, Mapy.cz, MapTiler, CARTO), route opacity adjustments, and tone filters.
