Kinetiqo Core Features & Capabilities

Select a core pillar below to explore technical details, visual samples, and configuration workflows.

⚡

1. Activity Sync & Data Grid

Fast incremental sync vs full audit reconciliation, SSE progress bars, and DataTables 2.x searchable grid with bulk deletion, CSV export, column reordering, and state persistence.

View Sync & Grid Details →
📊

2. Power, FTP & Fitness Analytics

Spider charts tracking best mean maximal power output over durations from 5s to 1 hour, 95% 20-min FTP history, Townsend VO₂max MAP estimation, and Banister CTL/ATL/TSB curves.

View Analytics Details →
🎨

3. Activity Posters & MEGA Stats

WYSIWYG activity poster generator with elevation profile charts, customizable fonts, 4:3 / 16:9 / 1:1 ratios, and Playwright PNG export. Includes Veloviewer-style heatmaps.

View Posters & Stats Details →
✍️

4. Strava Auto-Description Engine

Render dynamic Strava activity descriptions with 150+ placeholders across 6 activity buckets, milestone triggers (🎉), placement control, and server validation.

View Strava Sync Details →
🗺️

5. Interactive Canvas Maps

Leaflet map visualizer with Canvas renderer for thousands of GPS points, 7 map tile providers (OSM, Mapy.cz, MapTiler, CARTO), route opacity/color pickers, and tone overlays.

View Maps Details →
💾

6. Multi-DB Zero-ORM Warehouse

Clean Repository pattern with zero ORM overhead using raw parameterized SQL across PostgreSQL 12+, MySQL 8 / MariaDB 10+, and Firebird 3.0/4.0/5.0 with auto-schema migration.

View Multi-DB Details →
