Weather info

Enrich eligible synced activities with hourly historical weather along the GPS route.

Weather is fetched only during sync, stored per activity, and never requested on demand by AI. Configure VISUAL_CROSSING_API_KEY on the server to use Weather data by Visual Crossing. When Visual Crossing reports no remaining quota, Kinetiqo stops weather requests until the next UTC midnight. Fast sync uses this preference for newly added activities; full sync remains off unless explicitly enabled. Historical route sampling is hourly, not 15-minute.

GPS Track Simplification

Configure coordinate decimation scale (0–10) to speed up map reading and rendering.

Saved ✓
How Simplification & Persistence Work:
  • O(N) Haversine Sampling: Retains route terminus points and filters intermediate GPS points within the configured distance threshold.
  • Database Persistence: Stored in the profile.gps_simplification column in your database.
  • Environment Override Logic: If the GPS_SIMPLIFICATION environment variable is set, it updates the database on startup. If no environment variable is set, the stored database value is preserved (defaulting to 0 when unset).

How Fallback Models Work

If your primary model does not respond, encounters rate limits (429), or returns an error, Kinetiqo automatically attempts your fallback models in the order you selected them:

  • Fallback 1 — First alternate attempted
  • Fallback 2 — Second alternate if #1 fails
  • Fallback 3 — Third alternate if #2 fails

Click the diamond fallback icon on any model row to add or remove it. Up to 3 models can be assigned.

    Ollama (Local AI)

    Run local open-weights models on your own hardware or local network

    How to connect Kinetiqo to your Ollama machine
    • LAN Binding: If Ollama runs on a different PC on your network, set the environment variable OLLAMA_HOST=0.0.0.0:11434 on that PC and restart Ollama so it accepts connections from other devices.
    • Firewall: Allow inbound TCP port 11434 in Windows Defender Firewall on the Ollama host PC.
    • Server URL: Enter http://localhost:11434 (if running on same machine) or http://<PC_IP>:11434 (e.g. http://192.168.1.150:11434).
    • API Key: Optional. Leave empty for standard local/LAN Ollama instances. Only required if using a reverse proxy with Bearer authentication.
    • Recommended Models: For multi-turn tool calling and training analytics, 7B+ models like qwen2.5:7b-instruct or llama3.1:8b are strongly recommended. Smaller models (e.g. 1.7B) work for general chatting but may fail or hallucinate complex function calls.
    Default: http://localhost:11434
